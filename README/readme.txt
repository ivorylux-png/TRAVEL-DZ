📌 Description du site
Ce site web représente une agence de voyage en Algérie spécialisée dans le tourisme à travers les différentes wilayas du pays. Il permet aux utilisateurs de découvrir les plus belles destinations touristiques algériennes comme Alger, Oran, Constantine, Ghardaïa ou encore le Sahara.

Le site met en avant :

Des destinations populaires
Des images attractives
Des descriptions culturelles et touristiques
Une interface simple et moderne

L’objectif principal est de promouvoir le tourisme local et faciliter la découverte du patrimoine naturel et culturel de l’Algérie.

🎯 Fonctionnalités principales
🏝️ Affichage des wilayas touristiques
📷 Galerie d’images pour chaque destination
📄 Description détaillée de chaque lieu
📞 Page de contact pour les réservations
🧭 Navigation simple via un menu (navbar)
🛠️ Instructions d'utilisation


Ouvrir le site
Lancer le fichier index.html dans un navigateur (Chrome, Edge, etc.)
Naviguer dans le site
Utiliser le menu en haut pour accéder aux différentes pages :
Accueil (Home)
Destinations
Contact
Explorer les destinations
Cliquer sur une wilaya pour voir :
Les images
La description
Les activités disponibles
Contacter l’agence
Aller à la page Contact
Remplir le formulaire (Nom, Email, Message)
Cliquer sur envoyer
